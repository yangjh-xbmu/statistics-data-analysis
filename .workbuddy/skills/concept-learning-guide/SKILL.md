# 溯源式概念学习手册

## 适用场景

用户给出一个概念（如 Agent Skills、渐进式披露、某算法），要求生成用于学习的资料。
产出物：单页 HTML，放在项目根目录，命名为 `<概念英文小写连字符>-guide.html`。

## 工作流

### 第 1 步：溯源研究（不可跳过）

1. WebSearch 查概念的**原始出处**：首发博客、官方文档、标准站点、官方开源仓库。
2. 只以一手来源为准整理内容；二手解读仅用于辅助理解，不进正文。
3. 记录每个关键事实的来源 URL，供第 5 节"溯源"引用。

### 第 2 步：设计原则（少即是多）

- **文字最少化**：每节 = 一句 lead（核心结论加粗）+ 一张可视化。解释文字 ≤ 2 行。
- **颜色克制**：仅一个强调色（陶土橙 `#C4633F` 系）+ 中性灰阶 + 正确/错误两个语义色。
- **无多余图标**：不用 emoji、不用图标库；视觉层级靠字重、留白、编号（01/02/03…）。
- **降低认知负荷**：一屏只讲一件事；每张图配一行 caption。

### 第 3 步：页面结构（六节模板）

```
header  → 概念名 + 一句话定义 + 3 个事实 chip
01 它是什么   → 最小组成，左右对照图（结构 vs 文件内容）
02 核心设计   → 最关键机制的一张分层图
03 运行全程   → 状态变化的时序图（4 步以内）
04 铁律      → 3–5 条规则，编号列表，每条一行加粗 + 一行解释
05 溯源      → 每个原始出处一张卡片：标题 / 说明 / URL，全部 target="_blank" 可点击验证
06 自测      → 见第 4 步
```

- 可视化一律手写 SVG（`viewBox="0 0 680 H"`），不用图表库。
- SVG 文字用 `.svgtext` class 统一字体，跟随页面主题。

### 第 4 步：自测题（难度递进）

- 6 题左右，分三级：**基础·识别** → **进阶·理解** → **挑战·应用**。
- 每级题量均衡；错误选项要"像真的"（来自常见误解）。
- 每题带解析：答错时指出该回到哪一节重看。
- 结束显示总分 + 分级得分 + 一句 verdict。

### 第 5 步：质检（发布前必查）

- [ ] 每个事实都能在第 5 节找到可点击的出处
- [ ] 每节正文不超过"一句 lead + 一张图"
- [ ] 页面只出现一种强调色
- [ ] 测试题难度标注正确、递进成立
- [ ] **CSS 选择器作用域检查（曾踩坑）**：
  quiz 的选项样式必须写成 `.opts .opt{…}` 而非裸 `.opt{…}`。
  裸类名会命中页面其他位置的同名 class（本次 `.opt` 同时用于目录树
  `<span class="opt">`，导致元素叠加错乱）。通用教训：**单页 HTML
  内的组件样式，一律以容器选择器收窄作用域**。
- [ ] **JS 字符串内的引号检查（曾踩坑）**：
  quiz 数据用 `"` 定义字符串时，正文里的引用措辞不得再用 ASCII 直引号
  （会截断字符串导致整个 quiz 不渲染）。中文语境一律用「」或“”。

## 边界

- 不用于多章节教材或整门课程——那是 learn-studio 的职责。
- 不生成 PPT/PDF——如需演示或文档格式，转 presentation / docx 技能。
