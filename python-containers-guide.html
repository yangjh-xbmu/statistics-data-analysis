运算符与容器

值怎么变，值怎么排 —— 运算符把值合成新值，容器把值排成结构。列表是一列，字典是一行，列表套字典就是一张表。

除法 / 恒返回浮点数 下标从 0 起，切片含头不含尾 列表套字典 = 一张表
01

它是什么 —— 值从哪里变出来

运算符是把值变成新值的动作。同一批符号，作用在不同类型上给出不同结果——分不清类型，就分不清结果。

▲ 除法 / 永远给浮点；// 向负无穷取整（不是向 0 截断）——这正是 -7 // 2 = -4、-7 % 2 = 1 的来由

02

核心设计 —— 取值的两条路

容器是一个名字装下多个值。取出来只有两条路：按位置（列表，下标从 0 起）或按名字（字典，键必须唯一）。

▲ 官方原文：切片「包含开始，但不包含结束」，所以 s[:i] + s[i:] 总等于 s；下标越界报 IndexError，切片越界自动截断

一句带过（本次只需认得）：元组 (78, 82) 是不可变的一行，可以当字典的键；集合 set([1, 1, 2]) → {1, 2} 是自动去重的一袋值，没有顺序。

03

运行全程 —— 列表套字典就是一张表

表的两边是同一份东西：列表的每一项 = 表的一行，字典的每个键 = 表的一列。认下这一点，第 3 次课的 pandas 就只是换了一层皮。

▲ 官方教程对字典的定义：「可以把字典理解为键值对的集合，但字典的键必须是唯一的」

04

五条铁律

1
/ 永远给浮点数，要整数商就用 //
// 的结果向负无穷取整，不是向 0 截断：7 // 2 = 3，-7 // 2 = -4。余数跟着除数走，-7 % 2 = 1。
2
下标从 0 起，切片含头不含尾
取第 1、2 个用 s[0:2]。下标越界报 IndexError，切片越界不报错——只给你剩下的部分。
3
赋值不复制数据 —— b = a 之后改 b 就是改 a
官方原话：「简单赋值绝不会复制数据」。真要一份互不影响的副本，用切片 a[:] 做浅拷贝。
4
字典的键必须唯一且不可变
字符串、数字、元组可以当键，列表不行。d[key] 取不到会 KeyError，不确定有没有就用 d.get(key, 默认值)。
5
会改列表的方法只动手、不返回结果
append、sort、remove 的返回值都是 None。写 s = s.sort() 会把整个列表换成 None。
