运算符与表达式

运算符把值算成新值 —— 算什么，不看你写了哪个符号，看两边是什么类型。

除法 / 恒返回浮点数 // 向负无穷取整 类型不对 → TypeError

01

它是什么 —— 值从哪里变出来

运算符是把值变成新值的动作，一写一算叫一个表达式。七个算术符号先认全，剩下三个是留给统计用的。

▲ 除法 / 永远给浮点；// 向负无穷取整（不是向 0 截断）—— 这正是 -7 // 2 = -4、-7 % 2 = 1 的来由

02

核心设计 —— 结果由类型决定，不由符号决定

同一个符号，两边是数字就做算术，两边是文本就做拼接。类型不对，不是「算错了」，是根本没有这条运算法则。

▲ 官方对 TypeError 的说法是「类型不支持这个操作」—— '10' + 5 报的是 can only concatenate str (not "int") to str，想加就先 int('10') + 5

03

运行全程 —— 先算，再格式化

计算和显示是两件事：运算符产出的是数字，f-string 才决定它长得像什么。这也是为什么「保留两位小数」不该动计算过程。

▲ .2f 是格式规格：定点、两位小数。avg 本身一个字节都没变，变的只是显示

04

五条铁律

1
/ 永远给浮点数，要整数商就用 //
// 的结果向负无穷取整，不是向 0 截断：7 // 2 = 3，-7 // 2 = -4。余数跟着除数走，-7 % 2 = 1。
2
结果由类型决定，符号不对是 TypeError
'10' + 5 不是「算出 15 以外的东西」，而是没有这条法则；想相加先转换类型。'3' + '5' 得到的是 '35'。
3
** 比一元 - 优先级高
官方脚注：-3**2 被解释成 -(3**2)，结果是 -9；要 9 得写 (-3)**2。拿不准就加括号。
4
别拿 round() 当「四舍五入」，要位数就用 f-string
两个倍数同样接近时它向偶数取整：round(2.5) 是 2，round(3.5) 是 4；再加上二进制浮点本身的误差，显示位数应该交给 f"{x:.2f}"。
5
= 是赋值，== 才是比较
比较与逻辑运算给出 True / False，正好是下一课 if 与 for 的开关；混用 = 与 == 是本课最常见的低级错。
