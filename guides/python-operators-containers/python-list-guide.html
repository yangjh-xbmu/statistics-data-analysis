列表

一个名字装下有序的一列值 —— 按位置取，下标从 0 起，切片含头不含尾。

下标从 0 起 切片含头不含尾 赋值不复制数据
← 运算符与容器 · 系列路径 ›列表
01

它是什么 —— 有序的一列值

列表是把一列值放进一个名字里，并且记住它们的先后。顺序不是装饰，换位置就是另一列数据。

▲ 官方教程：「最常用的列表，是用方括号标注，逗号分隔的一组值」；「和字符串一样，列表也支持索引和切片」

02

核心设计 —— 切片是一把含头不含尾的尺

切片 s[i:j] 的含义是取下标 i 到 j 之前：所以 s[1:3] 给两个值，不是三个。记住这一条，其余全是推论。

▲ 官方原文：切片是「下标 k 满足 i <= k < j 的元素序列」，所以 s[:i] + s[i:] 总等于 s；但下标越界会直接 IndexError

03

运行全程 —— 一列成绩的四步

拿到一列数，动作永远是这四步：数个数、求和、求均值、看分布。四个内置函数，不改动原列表。

▲ 最大最小同族：max(s) 给 100，min(s) 给 62；这四个函数对列表和字符串一视同仁

04

五条铁律

1
下标从 0 起，负数从 -1 起倒数
s[0] 是第一个，s[-1] 是最后一个。五个值的合法下标只到 4，s[5] 就报 IndexError。
2
切片含头不含尾，而且越界不报错
s[1:3] 取下标 1、2 两个值。下标越界是 IndexError，切片越界却只是自动截断 —— s[2:99] 照样给你剩下的。
3
赋值不复制数据 —— b = a 之后改 b 就是改 a
官方原话：「简单赋值绝不会复制数据」。要一份互不影响的副本，用切片 a[:]（浅拷贝：只复制最外层）。
4
会改列表的方法只动手、不返回结果
append、sort、remove 的返回值都是 None。写 s = s.sort() 会把整个列表换成 None。
5
sorted() 返回新列表，s.sort() 改原列表
要保留原始顺序做对比，用 sorted(s)；确定不再需要原顺序，才用 s.sort()。
