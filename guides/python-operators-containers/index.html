03

术语表 · 全系列统一措辞

同一件事只有一种叫法，各页不得混称。

运算符
把值算成新值的符号（+ - * / // % **，以及比较与逻辑符号）
表达式
能算出一个值的写法，例如 sum(s) / len(s)
下标 / 索引
列表里位置的编号，从 0 起；负数从 -1 开始倒着数
切片
s[i:j]，取下标 i 到 j 之前 —— 含头不含尾
元素 / 项
列表里的一个值
键 / 值（键值对）
字典里成对的两半：键是名字、值是内容，写作 key: value
记录 / 个案
表的一行，在 Python 里就是一个字典
一列 / 变量
表里同一个键的一整列，也就是所有行 r[key] 拼起来
数据表 / 数据集
列表套字典：列表给行、字典给列，行列齐备
可变 / 不可变
列表可变、字符串与元组不可变；字典的键必须不可变（可哈希）
浅拷贝
只复制最外层容器，内部对象仍共享；a[:] 得到的就是浅拷贝
均值 / 样本量
均值是 sum(x) / len(x)；样本量就是 len(x) 给的个数
