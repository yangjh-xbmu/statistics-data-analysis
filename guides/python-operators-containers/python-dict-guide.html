字典

一条记录就是一个字典 —— 每个值都带着自己的名字（键）。按键取，键唯一、且必须不可变。

键唯一 取不到就 KeyError 不确定就用 d.get()
← 运算符与容器 · 系列路径 ›字典
01

它是什么 —— 一条记录

一条学生记录可以用列表装，也可以用字典装。区别是：列表要你记住「第 2 个是期末」，字典直接把名字写在值旁边。

▲ 官方定义：「可以把字典理解为键值对的集合，但字典的键必须是唯一的」；键是索引方式，与序列用连续整数索引不同

02

核心设计 —— 读一个键，三种结果

同一个键，写法不同就有三种命运：取到值、程序中断、或者拿到一个你给的默认值。选哪种写法，取决于这个键你有没有把握。

▲ 官方原文：「通过下标操作 (d[key]) 提取不存在的键的值会引发 KeyError。要避免……可改用 get() 方法，它会在字典不存在某个键时返回 None (或指定的默认值)」

03

运行全程 —— 写进去用方括号，读出来用 get

字典上唯一值得背下来的分工：写入用 d[key] = 值（键不存在就新增、已存在就覆盖），读取不确定就用 d.get()。

▲ 官方说明：「如果你使用已存在的键进行存储，则与该键相关联的旧值将丢失」—— 这是新增与覆盖共用一套语法的代价

04

五条铁律

1
字典按名字取，没有「第几号位」
d[0] 只有在你真的以 0 为键时才成立。要按位置取，那是列表的活。
2
键唯一，且必须不可变（可哈希）
字符串、数字、元组可以当键；列表不行——它可改，哈希值会变。{[78, 82]: 'x'} 直接 TypeError。
3
写入用 d[key] = 值：键不存在是新增，已存在是覆盖
两种意图共用一句写法，旧值静默丢失。要累加就得先读出来：d['n'] = d.get('n', 0) + 1。
4
读取不确定，就用 d.get(key, 默认值)
d[key] 取不到直接 KeyError 中断。真实数据里字段常有缺，这一条会救你很多次。
5
len(d) 数的是键值对个数；list(d) 给键的列表
d.keys() / d.values() / d.items() 三种视图，分别给你键、值、成对的 (键, 值)。

原始出处 · 点击验证

数据结构 · 5.5 字典
「字典是以键来索引的，键可以是任何不可变类型」；「可以把字典理解为键值对的集合，但字典的键必须是唯一的」；「花括号 {} 用于创建空字典」；「提取不存在的键的值会引发 KeyError……可改用 get()」；「list(d) 返回该字典中所有键的列表，按插入次序排列」
docs.python.org/zh-cn/3/tutorial/datastructures.html#dictionaries
内置类型 · 映射类型 dict
映射以可哈希对象为键；d[key] 取不存在的键引发 KeyError；get(key[, default]) 与 setdefault 的行为差异；keys / values / items 三种视图
docs.python.org/zh-cn/3/library/stdtypes.html#mapping-types-dict
术语表 · hashable（可哈希）
可哈希的对象在其生命期内哈希值不变、可与其他对象比较；不可变类型通常可哈希，列表等可变容器不可 —— 第 02 节右下角那个红框的依据
docs.python.org/zh-cn/3/glossary.html#term-hashable
内置函数 · len
对字典返回键值对的个数；对列表、字符串返回元素个数
docs.python.org/zh-cn/3/library/functions.html#len
术语表 · mutable（可变）
「可变对象可以改变其值，值改变后 id() 不变」—— 这就是列表不能当键的原因
docs.python.org/zh-cn/3/glossary.html#term-mutable
