03

术语表 · 全系列统一措辞

同一件事只有一种叫法，各页不得混称。

解释器
真正执行 Python 代码的程序（python.exe / python3）
编辑器
你写代码的地方（VS Code），它自己不执行代码
包
第三方代码库（pandas、numpy），装在解释器的环境里
单元格 / cell
Notebook 里的一段可独立运行的内容块，分代码与 Markdown 两种
内核 / kernel
常驻内存的 REPL 进程，Notebook 里的代码由它执行，变量也活在它里面
名称 / 名字
变量名。它不装数据，只是指向对象
对象
内存里的数据本身，有类型（int / float / str / bool 等）
异常
程序运行期错误对应的对象，有类型名与说明
Traceback
异常的调用路径记录；最后一行是类型与原因，从下往上读
