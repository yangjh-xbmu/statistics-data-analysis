Python 运行环境

解释器、编辑器、包管理是三个独立程序，各管一段

当前稳定版 3.14.7 编辑器不执行代码 包装在当前解释器的环境里
01

它是什么

三个独立程序各管一段：编辑器只写文件，解释器才执行，包藏在解释器的目录里。

▲ 编辑器写文件，解释器读并执行，import 时去自己的包目录找模块

02

核心设计 —— PATH 与当前环境

命令只认 PATH 里第一个解释器，而每个解释器都有自己的包目录，pip 装到「当前这个」里。

▲ PATH 上排着多个解释器，命中的第一个拥有专属的包目录

03

运行全程 —— 四步跑通

从保存文件到看到结果，关键一步是终端按 PATH 找到到底是哪个解释器在执行。

▲ 四步串起来：写文件 → 找解释器 → 执行 → 出结果或报错

04

五条铁律

1
编辑器不执行代码
编辑器只负责把 .py 文字写到硬盘，运行交给解释器。
2
系统可以装多个解释器，命令只走 PATH 里第一个
终端敲 python 时按 PATH 顺序命中第一个，后面的不生效。
3
包装在当前解释器的环境里，换解释器就换包
每个解释器有独立的 site-packages，pip 只装进「当前这个」。
4
项目用虚拟环境（venv）隔离依赖
每个项目建独立 venv，依赖互不污染、版本各管各的。
5
安装 Python 时要勾 Add to PATH，否则命令找不到
漏勾后终端走 PATH 找不到解释器，python 命令会报找不到。
